# Controle Financeiro Pessoal (Desktop)

Aplicativo desktop em Python com Tkinter para gerenciar receitas,
despesas e metas mensais. Interface intuitiva, suporte a CSV e controle
organizado para uso diário, totalmente offline e leve.

## 🚀 Funcionalidades

-   Cadastro de receitas e despesas\
-   Edição e exclusão de lançamentos\
-   Categorias personalizadas\
-   Importação e exportação de CSV\
-   Metas mensais por período\
-   Sistema de login\
-   Execução em tela cheia

## 🛠️ Tecnologias

-   Python\
-   Tkinter\
-   SQLite

## 📦 Como executar

``` bash
python app.py
```
